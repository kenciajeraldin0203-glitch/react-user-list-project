# React User List

This project implements the React assignment from the provided document.

## Requirements implemented

- `useState()` stores the users.
- `useEffect()` calls the API when the component loads.
- `fetch()` retrieves the user data.
- Displays User ID, Name, Username, and Email.
- Displays `Loading...` while the request is in progress.
- Displays an error message if the request fails.
- API: https://jsonplaceholder.typicode.com/users

## Run the project

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

http://localhost:5173
